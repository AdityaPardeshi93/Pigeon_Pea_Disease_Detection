About This Project

Deep Learning Model

Built using TensorFlow/Keras with Convolutional Neural Networks (CNN) architecture. Trained on thousands of pigeon pea leaf images to achieve high accuracy in disease classification.

Web Application

Developed with Python Flask backend and modern HTML/CSS/JavaScript frontend. Features real-time predictions, beautiful UI, and responsive design for all devices.

Disease Classes

Classifies pigeon pea leaves into four categories: Healthy, Leaf Spot, Leaf Webber, and Sterilic Mosaic with confidence scores and severity levels.
